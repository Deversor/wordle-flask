Word List Management (FEATURE IMPLEMENTATION)

 To provide a way to manage a custom list of 5-letter words through a RESTful API with full CRUD functionality

#Customize the Word Pool
 Instead of relying only on the built-in word list from NLTK we can now:
   Add our own 5-letter words
   Remove inappropriate or unwanted ones
#Extend the App's Use Case
 The game now also acts like a word list manager, which could be useful in:
   Vocabulary learning apps
   Language training tools
# Provides Frontend Control
  The added page lets users interact with the word list visually — no need for Postman or curl. It's now:
    Easy to view all words
    Add new ones via a form
    Delete or update with buttons
